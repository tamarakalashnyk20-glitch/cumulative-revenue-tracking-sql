# cumulative-revenue-tracking-sql
## Revenue Prediction Fulfillment Analysis

This project analyzes cumulative revenue performance against forecasted targets using BigQuery SQL.

Key Features

Combined revenue and prediction datasets using UNION ALL
Calculated cumulative revenue and cumulative forecast values
Used SQL window functions for running totals
Measured daily fulfillment percentage against predicted targets
SQL Concepts Used
JOIN
UNION ALL
Aggregate functions
Window functions (SUM() OVER)
Grouping and date-based analysis

Business Goal

Track how actual revenue performance aligns with planned revenue targets over time and identify fulfillment trends by date.
